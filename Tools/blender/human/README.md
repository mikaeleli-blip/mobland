# Human base

`base.obj` and the `.target` files are from MakeHuman (makehumancommunity/makehuman), released as **CC0**
(see the header of each file). `mhbody.py` loads them without MakeHuman; `gangster.py` builds clothed characters
on top; `sheet.py` renders a front/left/back/right model sheet.

    python Tools/blender/human/sheet.py out.jpg italian_01
